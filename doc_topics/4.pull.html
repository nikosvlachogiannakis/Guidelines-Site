Pulling Changes and Handling Conflicts

Basic Concept

When collaborators push changes to GitHub, your local repo becomes “behind” the remote version. You'll want to:

  • Fetch their updates
  • Review what changed
  • Merge or rebase safely

All without overwriting your own uncommitted work.

Without LazyGit

1. Save your current work

git status

If needed:

git add .
git commit -m "Brief explanation of what changes were made"

Or stash:

git stash

2. Fetch remote changes

git fetch origin

3. See what changed (Optional)

git diff main origin/main

To view commits:

git log main..origin/main --oneline

4. Merge changes

git pull origin main

Equivalent to:

git fetch origin
git merge origin/main

5. Restore Stashed Work

git stash pop

Then go to VS Code and resolve conflicts and add, commit and push the changes to GitHub.

LazyGit Workflow

Summary Table

Step Action Key Description
1 Open LazyGit lazygit Run lazygit inside the repository
2 Fetch updates f Fetch remote changes without merging
3 Pull changes p Pull changes from GitHub
4 View conflicts — Conflicted files appear in red
5 Resolve conflicts m Choose conflict resolution strategy
6 Use ours y Keep your local version
7 Use theirs t Keep remote version
8 Use both b Combine both versions
9 Edit manually e Edit conflict markers manually
10 Stage resolved space Mark conflict as resolved
11 Commit merge c Save merge resolution
12 Push changes P Upload to GitHub

Full LazyGit Workflow

1. Open LazyGit

lazygit

You will see panels for branches, files and commits.

2. Fetch Updates

Press:

f

This fetches remote updates without merging them.

3. Pull Changes

Press:

p

Select the remote and branch.

If there are no conflicts, Git merges automatically.

Handling Conflicts

Conflicted files appear in red.

Use:

  • m → Open merge menu
  • e → Edit file manually
  • d → View diff

Resolve Conflicts

  • y → Use ours
  • t → Use theirs
  • b → Use both
  • e → Manual edit

After fixing the file:

space

This stages the resolved file.

Commit the Merge

c

This commits the resolved merge.

Push Changes

Press:

P

This pushes the branch to GitHub.

Pro Tips

  • h → View commit history
  • u → Undo last action
  • x → Abort merge or rebase
  • b → Switch branches

Force Reset Local Repo

If you want to completely discard local changes:

git fetch origin
git reset --hard origin/main
git clean -fd
